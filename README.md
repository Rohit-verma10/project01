# AgriVision AI

AI-powered Crop Recommendation System

## Features

- User Authentication
- Crop Prediction using Machine Learning
- Prediction History
- Dashboard Analytics
- FastAPI Backend
- PostgreSQL Database

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Scikit-Learn

## Run Project

```bash
pip install -r requirements.txt
python -m uvicorn backend.app.main:app --reload
```
